# Passport Launcher 0.4.1 界面

0.4.0 移除社区下载器，保留本地 BIN 上传安装，并使用共享 Flash 替代固定槽。0.2.0 网页安装曾获所有者确认，本版实机验收仍待进行。

## 应用库与控制

240×320 屏幕包括标题/电量、可滚动卡片列表和控制/状态页脚。主菜单用更大加粗的 Passport Launcher 标题替代 Your library，以不可选分隔线区分应用和系统操作；About 主菜单项不显示开发者，署名保留在 About 内。应用库只列可启动应用，并显示安装数量和剩余 KiB，无空槽选项。无 ROM 时显示安装提示。

上/下移动整行圆角高亮，OK 进入/启动；选中长标题从右向左连续滚动。轮询、电量和倒计时不会重启标题动画。列表自动滚动保持选中项可见，长按 OK 返回。

主操作为 Install a ROM、Manage apps、Auto start: On/Off 和 About。安装页分别显示网络、密码、网页地址和当前容量。网络保持 Passport Launcher / aipassport / http://192.168.168.1。

## 仅 BIN 网页

只接受 `.bin`，拒绝 `.passport` / `.passportos`，旧公共包安装接口已移除。原生 SDK 2 的 app-only BIN 保持声明身份。保留提取、哈希、芯片和额外分区检查。代码按剩余共享空间分配，详见[共享存储](shared-storage.zh_CN.md)。内部 HTTP 头不是提供给用户的应用文件格式。

网页显示共享总量、剩余量及扣除设置预留后可容纳的最大新 ROM，并先发送 512 字节元数据检查。更新可回收自己的代码并保留私有数据，安装器在锁内重复检查。不能放入的 ROM、索引耗尽或不兼容布局会在设备显示原因。通知和预检查不写代码或应用 NVS。

社区下载辅助入口已经移除。可选旧版设置导入与 ROM 上传分开，旧开发包和归档只作历史兼容资料。

网页显示真实上传百分比，上传后改为等待设备安装/校验的不定进度条，仅最终成功响应才显示 Installation complete。预检查拒绝、HTTP 错误、网络中断/超时均不会报告成功，操作期间禁用上传控件。移除旧 QSO 设置导入说明段，保留其可选兼容动作。About 加入开发者 GitHub，网页底部显示 9W3SPY 与 GitHub 超链接。

## 卸载与保存数据

Manage apps 列出应用和需清理的未完成条目。选择后显示完整名称及“永久删除全部保存数据和设置”警告，默认选中 Cancel。上/下选择，OK 确认；取消或长按返回均不删除。

确认卸载擦除代码及全部私有存储，包括社区默认 NVS 快照。网页同样警告并确认。设备和网页都绑定稳定 ID，防止位置被复用后误删其他应用。部分失败保留不可启动清理条目，完成卸载后释放代码和数据空间。

## 自动启动

默认目标为 Last booted app（上次启动应用）。进入 Auto start → Startup app，可选择默认跟随模式或固定任一已就绪应用；目标选择不改变独立开关。固定目标按稳定 ID 保存，手动运行其他应用或正常更新不会改变它；卸载该目标会恢复默认跟随。中断/缺失目标不会自动运行。倒计时高亮实际选中的启动应用。

On 在正常上电后显示高亮已配置启动应用和五秒倒计时，任意按键取消并进入应用库；Off 直接显示库。设置页保留开关和用途说明。截止时间已有输入优先取消。

社区 BIN 可正常冷启动自动运行，不需 SDK 回调；原生 SDK 2 应用需健康确认。软件复位、异常、看门狗和深睡眠唤醒进入启动器，不自动运行。恢复完成后才允许倒计时。尚未运行应用时 On 只保存偏好。

## About 与开源

设备主菜单和网页 About 使用 QSO 风格 Developed by 小字及突出 9W3SPY，显示版本、ESP-IDF 5.5.3、ESP32-C3 / 8 MB、MIT、板级支持和依赖许可，以及 Inspired by M5 Launcher / bmorcelli/Launcher。

网页 `/licenses.txt` 离线提供完整声明，保留原 FoloToy 版权并以确定性 gzip 嵌入，无需在 MCU 内解压完整文本。M5 Launcher 仅为设计灵感，未复制源代码。[许可总览](third-party.zh_CN.md)与根 LICENSE 为准。

## 安装与验证

已有 0.4.0 时，先断电重启、取消自动运行并等待菜单完成上次应用 NVS 快照，再将 **Passport-Launcher-0.4.1-update.bin 写入 0x0**，**关闭整片擦除**。校验的写入范围在 `0x190000` 前结束，保留应用、私有 NVS 和元数据，SDK 2/分区协议不变。合并前缀会重置平台/默认 NVS。更早固定槽版本需明确的全新迁移，不能套用本升级流程。

实机检查高亮/标题滚动、导航、BIN 上传、取消保留应用、确认卸载清空数据、开关持久化、冷启动倒计时/取消，以及设备和网页 About。卸载仅使用愿意删除的测试数据。

主机验证包括 10 个 ASan/UBSan C 可执行程序、24 项 Python 检查、浏览器/解析测试以及实际 QSO/Internet Radio 字节。2.5 MiB 模拟镜像通过生产流式安装/选择/上下文路径，第四应用保留私有数据。分配器测试 10,000 次操作、容量与碎片，启动测试覆盖表操作故障。实际锁定 LVGL / RGB565 / **48 KiB 池**覆盖完整 16 项应用库、滚动、确认/倒计时/About 和页面切换。预览来自主机渲染，不是实机截图。RF/堆/栈、实际执行、寿命和电气断电恢复尚待实机验证。
