# 验证、迁移与实机验收

实际构建身份与结果记录在 `validation-results.json`，对应调试文件按内容哈希保存于 `build/firmware/`。必须分别报告 Build、Host tests、Device tests、Unverified。本原型尚未刷写或通过实机验收。

## 自动检查

`bash tools/validate.sh` 使用 AddressSanitizer/UBSan 编译运行注册表/票据测试及带 I/O 故障桩的真实安装器，运行包损坏测试，使用 ESP-IDF 5.5.3 编译、合并、检查分区表 MD5/地址/边界/重叠/镜像一致性及 ELF 绑定，再归档匹配产物。环境追踪会阻止 LeakSanitizer，故仅关闭泄漏检查，仍保留地址与未定义行为检查。

安装器测试逐一让接收、保存、擦写、校验读取失败，确认破坏性写入前已有持久 INSTALLING，不影响其他应用或私有区，拒绝错误芯片/哈希/ABI，并检查保留与删除数据。这里的 SDK 镜像校验和 SHA 使用桩；独立包测试验证真实镜像校验值与 SHA。主机测试不能证明物理 NVS 原子性、Flash 时序或供电可靠性。

检查入口基于现有 FoloToy 校验归档流程调整，须核对最终 defaults、依赖锁与实际 sdkconfig。归档包含 OTA 初始化、引导器、表、应用、合并镜像、刷写参数、ELF 与 MAP。QSO/计数器包还须运行 `package_app.py verify`。示例项目引导器与表仅用于构建，不能作为安装载荷。

## 首次安装属于迁移

旧布局的 24 KiB 默认 NVS 与新的 OTA 选择区重叠。合并配置镜像会填充间隙，从 `0x0` 写入可能清除设置；旧代码也可能占用将来的应用槽。因此仅采用分段刷写不能证明兼容或位置为空。

获准刷写前，应确认板子/端口、JEDEC 容量及当前分区，明确需保留的数据。QSO 的 `monitor` 同时保存音量、通话组、调光、亮度及 Wi-Fi 档案（包括 `pN_s`、`pN_p`、`wifi_last_ssid` 与旧 Wi-Fi 键）；历史记录仅在 RAM，不是 Flash 数据库。旧布局尚可用时，采用已验证的工具导出应用记录，再验证导入同一 ID 的私有分区。0.1.1 已提供并主机验证仅数据导出/暂存/重试实现，见[迁移](migration.zh_CN.md)。**真实设备读取与恢复尚未验证，不能声称首次配置已保留实物设置。**

不将原固件读回或全 Flash 备份列为前提。用户数据导出与固件备份不同，不默认要求或授权全片擦除。制定可审查的迁移方案并获明确许可后，才可刷入准确校验的产物及初始化审核过的范围。不能刷旧产物、把纯应用刷到 `0x0` 或使用示例表。已安装 PassportOS 后，启动器维护可审核兼容分段升级以保留应用/数据，但这不保证首次布局转换安全。

## 实机验收

| 项目 | 预期结果 |
| --- | --- |
| 身份 | 核实 C3 修订、8 MiB JEDEC、USB 与真实引脚 |
| 全新启动 | 默认菜单、240×320 正确显示、圆角/字节序、按键、电池降级 |
| 手机安装 | 离线连接屏幕密码、上传有效包、退出页面关闭服务 |
| 校验 | 拒绝错误芯片、合并/超大/截断/损坏/ABI 错误载荷，不改受保护数据 |
| 独立执行 | A/B 计数器及 QSO 分别运行，重启回到启动器 |
| 数据归属 | 相同键保持不同值，QSO 设置/档案跨切换保留，同 ID 更新/重装保留数据 |
| 移除 | 普通移除保留数据与位置；明确删除数据仅释放选中 ID |
| 返回 | 计数器长按 OK、QSO Options 双击 OK 保存后返回；外设重初始化正常 |
| 自动启动 | 首次关闭；五秒窗口消费完整取消动作；异常或应用重启不自动启动；健康确认后正常上电可自动 |
| 掉电 | 在提交、擦写、验证、选择前后断电，启动器及其他应用可恢复，未完成应用可重试 |
| 元数据 | 损坏或缺失且数据残留时进入恢复，不自动格式化 |
| 压力 | 重复上传/切换，测栈水位、总堆/最大块、电池、超时与看门狗 |
| 最后恢复 | 实测 USB ROM 恢复路径，不猜 GPIO0/BOOT 接线，不改 eFuse |

可访问 USB 时先只读发现，再针对具体镜像与数据影响请求刷写批准；设备连接和编译通过都不代表许可。若当前环境无法接触用户 USB 总线，应在同样审核后本地操作并收集日志和观察，不能把成功下载当作实机通过。

固件检查从 defaults 生成隔离 sdkconfig，并保留为 `build/validated.sdkconfig`，不覆盖根目录本地设置。硬件电源键不在 MCU 输入接口中；应用应及时提交设置，不能依赖关机回调。

0.1.2 还运行组合管理器/SDK/引导器的[生命周期测试](lifecycle.zh_CN.md)，使用持久主机后端和真实 OpenSSL SHA，并测试输入/截止边界。协议样本不可执行，不运行 ESP32 应用，也不证明真实 NVS 页面恢复。
