简体中文

1. 本页安装清除应用及设置；保留数据请用GitHub升级说明。上/下选择、OK确认，长按OK返回。
2. 选Install a ROM，手机或电脑连热点Passport Launcher（密码aipassport），打开http://192.168.168.1。
3. 选.bin，点Install / update；等Installation complete。失败重选同一文件重试，空间不足先卸载闲置应用。
4. 长按OK回菜单，选择应用运行。重启返回启动器；倒计时按任意键取消自动运行。切换已装应用无需联网。
5. Auto start可开关，默认上次应用；Startup app可指定应用。

English

1. Installing the firmware on this page clears existing apps and settings. To retain data, follow the GitHub upgrade guide instead. Use UP/DOWN to select, OK to confirm, and hold OK to go back within the launcher.
2. Choose Install a ROM. On a phone or computer, join the Passport Launcher hotspot (password: aipassport), then open http://192.168.168.1.
3. Select a local .bin and press Install / update. Wait for Installation complete. If it fails, reselect the same file and retry; if space is insufficient, uninstall an unused app first.
4. Hold OK to return to the menu and choose an app. Restart or power-cycle to return to the launcher; any button cancels the startup countdown. Switching installed apps needs no internet.
5. Auto start can be switched on or off, follow the last-booted app, or use Startup app to pin another app.
